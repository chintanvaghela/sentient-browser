# Security Policy

## Supported Versions

We actively support and provide security updates for the following versions of Sentient Browser:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Sentient Browser, please do **NOT** open a public issue. Instead, report it through one of the following channels:

1. **GitHub Security Advisory**: Open a private draft security advisory under the repository's **Security** tab (`https://github.com/chintanvaghela/sentient-browser/security/advisories/new`).
2. **Email Disclosure**: Email the maintainers directly with details of the vulnerability, reproduction steps, and potential impact.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
- A clear description of the vulnerability.
- Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
- Impact assessment (e.g., unauthorized access, local privilege escalation, unexpected data exposure).
- Any proposed remediation or patches, if available.

### Response Timeline

- **Initial Response**: Within 48 hours acknowledging receipt of your report.
- **Triage & Assessment**: Within 5 business days confirming validity and assigning severity.
- **Fix & Disclosure**: We will collaborate with you to release a patch and coordinate public disclosure once the fix is deployed.

Thank you for helping keep Sentient Browser and our users secure!
